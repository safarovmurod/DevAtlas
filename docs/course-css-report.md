## Се дарси намуна

### Рӯзи 1: CSS ва селекторҳои аввал

Рӯзи 1. CSS ва селекторҳои аввал. Усулро дар вазифаи мустақил истифода бурда, натиҷаро дар браузер санҷед.

**Section-ҳо:**

- **Лавҳа ва ранг** — Усто аввал лавҳаро месозад, баъд онро ранг мекунад. HTML низ мазмунро муайян мекунад: сарлавҳа, нарх ва пайванд. CSS намуди ин элементҳоро танзим мекунад. Селектор нишонии гирандаи услуб аст. Қоидаи p абзатсҳоро интихоб мекунад, color ранги матнро дигар мекунад. Худи калимаҳо бетағйир мемонанд.
- **Нишонии класс дар қоида** — Дар HTML номи класс бе нуқта меояд: class="price". Дар CSS нуқта классро аз номи тег фарқ мекунад. Дар қавсҳои фигурӣ «хосият: арзиш;» навишта мешавад. Дар ин мисол танҳо нарх сабз мешавад. Сарлавҳа одӣ мемонад. Бо блоки style мисоли аввалро дар як файли HTML санҷидан мумкин аст.
- **Як класс барои чанд нарх** — Агар ду абзатс class="price" дошта бошанд, қоида ба ҳар ду таъсир мекунад. Мағоза бе такрори CSS нархномаҳои якхела мегирад. ID барои як элементи нодири саҳифа аст; классро такрор кардан мумкин. Ба HTML моли дуюм илова кунед. Баъд санҷед, ки ивази як ранг ҳар ду нархро нав мекунад.
- **Нуқта, дунуқта ва сабт** — Ба ҷойи .price танҳо price нанависед: он теги мавҷуднабуда меҷӯяд. Байни color ва арзиш аломати баробар нагузоред: CSS дунуқта мехоҳад. Пеш аз нав кардани саҳифа файлро сабт кунед. Агар ранг тағйир наёбад, номи класс ва қоидаро дар панели Styles-и абзорҳои браузер санҷед.

**Саволҳо:**

1. CSS чист? Вариантҳо: 1) Забони тавсифи намуди элементҳои саҳифа; 2) Забони иваз кардани мазмуни элементҳо; 3) Забони муайян кардани нишонии саҳифа. Ҷавоби дуруст: 1. Hint: Мазмуни лавҳаро аз ранги он ҷудо кунед.
2. Ду p дорои class="price" ҳастанд. Кадомаш сабз мешавад? Вариантҳо: 1) Танҳо абзатси якуми класс; 2) Танҳо абзатси дуюми класс; 3) Ҳар ду абзатси ҳамин класс. Ҷавоби дуруст: 3. Hint: Як класс ба чанд элемент дода мешавад.
3. Чаро price { color: green; } class="price"-ро намеёбад? Вариантҳо: 1) Ин ҷустуҷӯи ID ба ҷойи класс аст; 2) Ин ҷустуҷӯи тег ба ҷойи класс аст; 3) Ин ҷустуҷӯи матн ба ҷойи класс аст. Ҷавоби дуруст: 2. Hint: Ба аломати пеш аз номи селектор нигаред.

**Практика:**

Қадами 1. notice.html бо сарлавҳа ва ду эълони p созед.
Қадами 2. Ба p-и аввал urgent ва ранги #9f1239 диҳед. Дуюмро бе класс монед.
Қадами 3. p-и сеюмро бо urgent илова кунед: ҳар ду эълони таъҷилӣ бояд ҷигарӣ шаванд.
Қадами 4. Файлро дар браузер кушоед, натиҷаро санҷед ва тамоми HTML бо CSS-ро ба муҳаррири машқ гузоред.

**Критерияҳо:**

- Класси urgent ду эълонро #9f1239 мекунад.
- Ранги абзатси миёна тағйир намеёбад.
- Матн ва тартиби се эълон нигоҳ дошта шудаанд.

Solution: HTML-и пурраи 440 аломат. Нусхаи иҷрошаванда дар `src/content/courses/css.json`, дарси `css-day-01` аст.

### Рӯзи 15: Минтақаҳои номдор ва span

Рӯзи 15. Минтақаҳои номдор ва span. Усулро дар вазифаи мустақил истифода бурда, натиҷаро дар браузер санҷед.

**Section-ҳо:**

- **Нақшаи ҳуҷраҳо дар тарҳ** — Дар нақшаи устохона ҳуҷраҳо ном доранд: даромад, анбор, ҷойи кор. Grid-template-areas ҳам қисмҳои шабакаро номгузорӣ мекунад. Ҳар сатри дар нохунак буда як қатор, ҳар ном як хона аст. Элемент бо grid-area ҷой мегирад. Нақшаи саҳифа бе ҳисоби координатаҳо фаҳмо мешавад.
- **Фосилаҳо ва хонаҳои якҷоя** — gap фосилаҳои байни роҳҳои шабакаро медиҳад: row-gap — байни сатрҳо, column-gap — байни сутунҳо, сабти кӯтоҳи gap: 16px 24px аввал сатрҳоро, баъд сутунҳоро медиҳад; як арзиш — ба ҳар ду меҳвар. Фарқи калидӣ аз усулҳои куҳна: фосила ба шабака тааллуқ дорад, на ба элементҳо, бинобар ин дар аввалин ва охирин элемент фосилаи бефоидаи берунӣ нест — мушкилии ҳамешагии ҳаки margin «ба ҳама ғайри охирин». gap дар flex ҳам кор мекунад — ин хосияти ҷараёнҳои тарҳ аст, на танҳо grid. Сатҳи дигари нармӣ span-ҳо медиҳанд: grid-column: span 2 элементро ба ду сутун, grid-row: span 3 — ба се сатр кашида мекунад.
- **Росткунҷаи минтақаи номдор** — grid-template-areas макетро бо калимаҳо тавсиф мекунад: ҳар сатри шабака — сатри дар нохунак, ҳар ҳудуд — ном. Шабакаи саҳифа: header header / sidebar main / footer footer — шапка бо тамоми паҳно, дар ҷониб меню, дар рост муҳтаво, зерпарда боз бо тамоми паҳно. Ба ҳар элемент ҳудуд тавассути grid-area таъин мешавад: grid-area: header. Қоидаҳои сахт: ҳар сатри нохунак як шумораи ном бояд дошта бошад; ҳудуд бояд росткунҷа бошад; нуқта маънои хонаи холӣ дорад. Афзалият аз span-ҳо — хондашавӣ: макет ҳамчун сурати ASCII хонда мешавад ва инсони нав сохторро дар чанд сония мефаҳмад.
- **Span танҳо дар шабакаи худ кор мекунад** — Минтақаи номдорро ба шакли Г насозед: ҳар минтақа бояд росткунҷа бошад. Шумораи хонаҳоро байни сатрҳои қолаб иваз накунед. Ба фарзанди блоки одӣ span дода, таъсир ба шабакаи берунаро интизор нашавед. Агар дар main шабака лозим бошад, аввал ба худи main display: grid диҳед.

**Саволҳо:**

1. gap: 16px 24px чӣ мекунад? Вариантҳо: 1) 24px байни сатрҳо, 16px байни сутунҳо; 2) 16px фосила аз ҳар ҷониб; 3) 16px байни сатрҳо, 24px байни сутунҳо. Ҷавоби дуруст: 3. Hint: Дар gap аввал сатрҳо, баъд сутунҳо меоянд.
2. Элементро ба ҳудуди header чӣ тавр мегузоранд? Вариантҳо: 1) area: header; 2) grid-area: header; 3) grid-name: header. Ҷавоби дуруст: 2. Hint: Номи минтақа элементро ба қолаби волидайн мепайвандад.
3. Элемент бо grid-column: span 2 … мегирад Вариантҳо: 1) Ду сутуни ҳамсояи ҳамин шабака; 2) Танҳо сутуни дуюми ҳамин шабака; 3) Нисфи паҳноии як сутуни шабака. Ҷавоби дуруст: 1. Hint: Span роҳчаҳои grid-контейнери ҷориро мешуморад.

**Практика:**

Қадами 1. timetable.html созед: сарлавҳаи ҷадвал, рӯйхати рӯзҳо, дарсҳо ва ёддошт.
Қадами 2. Areas: "title title", "days lessons", "note note"; сутунҳо 100px ва 1fr, gap 12px бошанд.
Қадами 3. Дар lessons шабакаи ҷудои ду сутун созед; дарси аввал span 2 гирад.
Қадами 4. Файлро дар браузер кушоед, натиҷаро санҷед ва тамоми HTML бо CSS-ро ба муҳаррири машқ гузоред.

**Критерияҳо:**

- Сарлавҳа ва ёддошт ҳар ду сутуни беруниро мегиранд.
- Рӯйхати рӯзҳо сутуни 100px дорад.
- Дарси муқаддимавӣ ду сутуни дохилиро мегирад ва рӯзҳоро намепӯшонад.

Solution: HTML-и пурраи 910 аломат. Нусхаи иҷрошаванда дар `src/content/courses/css.json`, дарси `css-day-15` аст.

### Рӯзи 30: Ҷамъбаст: профили мутобиқшавандаи мутахассис

Рӯзи 30. Ҷамъбаст: профили мутобиқшавандаи мутахассис. Усулро дар вазифаи мустақил истифода бурда, натиҷаро дар браузер санҷед.

**Section-ҳо:**

- **Профил ҳамчун витринаи корӣ** — Усто ба муштарӣ корҳо, шартҳо ва роҳи тамосро нишон медиҳад. Профили мутахассис дар браузер ҳамин вазифаро дорад. HTML-и маънодор, қуттӣ, шрифт, Flexbox, Grid, мутобиқшавӣ ва ҳолатҳоро мепайвандем. Аввал маълумоти инсонро нависед. Баъд тарҳеро интихоб кунед, ки таҷриба ва роҳи тамосро равшан кунад.
- **Авто-шабакаи мазмуни дигар** — Мисол танҳо ҷадвали машваратро нишон медиҳад, на профили тайёрро. Он авто-шабака ва токени маҳаллиро ёдрас мекунад. Дар майдони васеъ ду сабт паҳлуи ҳам, дар танг зери ҳаманд. Матн озод мегузарад. Дар машқ усулро барои лоиҳаҳо ва мазмуни худ истифода кунед, на тамоми блокро нусха кунед.
- **Ҷадвали санҷиши профил** — 360px ва 1280px, баъд масштаби 200%, Tab ва reduced-motion-ро санҷед. Номи дароз илова карда, муваққатан ҳамаи лоиҳаҳоро бардоред. Маъноро санҷед: пайванди тамос кор кунад, сарлавҳаҳо мантиқӣ ва амалҳо дастрас бошанд. Мушоҳидаҳои воқеӣ ва хатоҳои ислоҳшударо назди код сабт кунед.
- **Санҷиши охир бе пинҳонкунӣ** — Баромадро бо overflow hidden-и умумӣ ислоҳ накунед. Пайвандҳои холӣ ва тугмаҳои беамал намонанд. Агар токени умумӣ ҳаст, рангро даҳҳо бор такрор накунед. Акси васеъ далели мутобиқшавӣ нест. Дар экрани танг аз номи инсон то пайванди тамоси ӯ тамоми роҳро гузаред.

**Саволҳо:**

1. Профилро аз чӣ сар кунем? Вариантҳо: 1) Аз соя, аниматсия ва рангҳои тасодуфӣ; 2) Аз мазмун, сарлавҳаҳо ва пайвандҳо; 3) Аз координатаҳои собити ҳамаи блокҳо. Ҷавоби дуруст: 2. Hint: Аввал муайян кунед, ки меҳмон чиро мефаҳмад.
2. Desktop хуб аст. Боз чиро санҷем? Вариантҳо: 1) Танҳо як акси дигари васеи саҳифа; 2) Танҳо тобиши нави заминаи асосӣ; 3) Паҳноии танг, масштаб ва роҳ бо Tab. Ҷавоби дуруст: 3. Hint: Акс як андоза ва як ҳолатро сабт мекунад.
3. Ҳоло лоиҳа нест. Қисм чӣ гуна бошад? Вариантҳо: 1) Бо сарлавҳа ва ҳолати холии фаҳмо; 2) Бо шабакаи холӣ ва баландии собити пешина; 3) Бо қисми асосии саҳифа пурра пинҳоншуда. Ҷавоби дуруст: 1. Hint: Набудани маълумот набояд қолабро вайрон кунад.

**Практика:**

Қадами 1. Profile.html барои Фарзона: сар, дар бораи худ, малакаҳо, се лоиҳа ва mailto созед.
Қадами 2. Токенҳо, Flexbox дар сар ва Grid-и лоиҳаҳо диҳед: то 700px як сутун, аз 700px ду. Hover-гузариш ва focus-visible илова кунед.
Қадами 3. 360/1280px, 200% масштаб, номи дароз, лоиҳаҳои холӣ ва reduced-motion-ро санҷед.
Қадами 4. Файлро дар браузер кушоед, натиҷаро санҷед ва тамоми HTML бо CSS-ро ба муҳаррири машқ гузоред.

**Критерияҳо:**

- Панҷ блоки маънодор ва mailto-и корӣ ҳастанд.
- Дар 360px баромад нест, аз 700px лоиҳаҳо ду сутунанд.
- Tab, масштаб, рӯйхати холӣ ва reduced-motion дастрасиро нигоҳ медоранд.

Solution: HTML-и пурраи 2530 аломат. Нусхаи иҷрошаванда дар `src/content/courses/css.json`, дарси `css-day-30` аст.
