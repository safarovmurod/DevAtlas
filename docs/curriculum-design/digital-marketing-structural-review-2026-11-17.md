# Digital Marketing course review — 17 November 2026

Status is RUNNING in the existing main checkout. This review owns `digital-marketing.json` and this source note. The initial audit found 30 scheduled days, three theory sections on every day, five questions per day, and missing linked feedback on all 30 days. Five code exercises already have executable JavaScript contracts on days 19, 20, 22, 23 and 26. Those contracts will be preserved.

The first full English read of the 30 lessons identified several factual and task/reference issues for the local authoring pass. CTR uses clicks over impressions, while the course calls visits clicks without defining that simplification. The existing UTM exercise accepts only simple bases but its task does not state that boundary. The email example deletes unsubscribed addresses without considering suppression. Cookie identifiers are described as anonymous. The sequential Wednesday/Sunday comparison is presented as a randomized A/B test. Acquisition CPA is confused with a customer's ticket price, a per-meeting cost becomes per-attendee, and the final project reference claims a real colleague test. Each correction will retain the original IDs and option positions.

Sources actually opened so far include [Google SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [Google Ads CTR definition](https://support.google.com/google-ads/answer/2615875?hl=en) and [Google Analytics data safeguards](https://support.google.com/analytics/answer/6004245?hl=en).
