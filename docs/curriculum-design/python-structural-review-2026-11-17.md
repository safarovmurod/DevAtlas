## Что исправлено

### 1. Дни 1–2: четвёртый раздел (вставка в позицию 1, без сдвига существующих)

- День 1 — «Порядок строк и повторное присваивание» / «Тартиби сатрҳо ва гузоштани дубора» / «Line order and reassignment»: Python выполняет строки сверху вниз, NameError при обращении до присваивания (какое слово ошибки читать), `total` хранит готовое число, а не формулу — вывод программы `36` и `60` после `price = 20`, затирание значения при повторном присваивании. Код с запускаемым примером прилагается; поле `output` намеренно не добавлялось, чтобы не сместить привязку теста documented-output.
- День 2 — «Что вернёт функция без return» / «Функсия бе return чӣ бармегардонад» / «What a function returns without return»: функция без `return` отдаёт `None`; `print` внутри функции не заменяет возвращаемое значение; `print(one, two)` → `None 5`; арифметика с `None` даёт `TypeError`. Код прилагается, `output` не добавлялся.

### 2. Третий вопрос `python-day-NN-q3` на 28 дней (1–11, 13–29)

Каждый новый вопрос: id `python-day-NN-q3`, ровно 3 варианта, дистракторы — реальные ошибки новичка (ждать, что Python «подождёт» определения; `insert` как `append`; `items.join(...)`; числа в `sys.argv`; `math` «подключается сам»; «B», потому что 95 >= 80 тоже истинно; и т. п.), `hint` и `relatedSection` заполнены, `answer` — короткое пояснение в трёх языках. Ничего не скопировано из существующих вопросов; существующие id, формулировки, варианты и `correctIndex` не тронуты.

`correctIndex` новых вопросов: на днях, где существующая пара различна, использовано недостающее значение из `{0,1,2}`; на днях с дублирующейся парой `(1,1)` выбрано поочерёдно 0/2, чтобы не создавать постоянный паттерн. Итог: `{0: 13, 1: (существующие), 2: 15}` — доминирование индекса снизилось (`answerSameIdx%` 66 → 45). Различающихся трёх индексов в дне достигнуто там, где это физически возможно без правки существующих вопросов (см. «Оставшаяся работа»).
