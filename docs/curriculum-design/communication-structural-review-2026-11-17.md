### 2. `hint` + `relatedSection` для 133 вопросов

Поля добавлены одновременно (требование schema `src/lib/courses/schema.ts`: `(hint === undefined) !== (relatedSection === undefined)` запрещено; `relatedSection < sections.length` после вставки). 133 вопроса получили только эти два поля — `id`, `question`, `answer`, `options`, `correctIndex` не тронуты (17 вопросов с существующими парами не тронуты вовсе, кроме индексной поправки day-27-q05 и day-29-q04, описанной выше). Hint — наводящий, не раскрывающий ответ дословно, ru/tg/en, tg ≠ ru; `relatedSection` указывает на раздел, который учит ответу (примеры: day-03-q02 → 3 «Ловушки слушания» после сдвига, day-09-q03 → 1 «Разобранный пример», day-10-q03 → 2 «Тихие и громкие», day-24-q04 → 1 пример с Ниной). Итог: 150/150 вопросов с парой hint + relatedSection.

### 3. Overlap — вердикт

- Дни 1, 2: `sections[1]` («Разобранный пример») строка-в-строка равна `practice.referenceAnswer` (ru/tg/en). Практика просит ученика переписать СВОЮ вымышленную фразу («сделайте нормально» на дне 1; собственная ошибка на дне 2), а разобранный пример — образец-эталон для ДРУГОГО входа («Срочно пришлите это»), то есть worked-example (trust-example), а не ответ на копируемое задание. По правилу «trust-example — сабт кун, тағйир надиҳ» записано, не менялось (совпадает с принятым вердиктом бизнес-foundations, где паттерн тот же). Внимание для следующего владельца: тест `tests/general-course-content.test.ts` для expanded-курсов запрещает referenceAnswer в body — `communication` в `expandedIntroductions` не входит, поэтому тест не ломается, но при возможном расширении списка правило включится автоматически.
- Остальные 28 дней: дубликатов referenceAnswer в prose не найдено (поиск первых 80 символов referenceAnswer по всем body трёх языков, оба направления). Решение практики ни в одной секции не напечатано.
